## ⏱️ Time & Space Complexity

I am also focusing on understanding the efficiency of algorithms using **Big-O notation**.

| Complexity | Example |
|------------|---------|
| `O(1)` | Accessing an array element |
| `O(log n)` | Binary Search |
| `O(n)` | Linear Search |
| `O(n log n)` | Merge Sort |
| `O(n²)` | Bubble Sort |
| `O(2ⁿ)` | Some recursive solutions |
